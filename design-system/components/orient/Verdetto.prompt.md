# Verdetto

orient composite. The quiz verdict (F-003): marks the picked and the right
option and shows a panel below the options.

- Right option: `teal-500` border, `teal-50` fill, mark ✓. Wrong pick:
  `red-500` border, `red-50` fill, mark ✕. Other options fade to 50 %.
- Panel: an Alert (soft) — teal with title *Giusto*, or red with title
  *Sbagliato — <nome>* — and the definition as body.
- **The rule it carries:** colour is never the only signal (2.006). Every
  verdict has a mark and a text title; a learner who cannot see red from
  teal reads the same result.
