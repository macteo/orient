# FacciaCarta

orient composite. The front and back of a card for each of the four card
types (3.002, F-004), at sizes `carta`, `tile`, `lista`.

- `simbolo`: front = pictogram SVG, black, centred on a white surface with a
  hairline border; back = small pictogram, reference Badge, name, definition.
- `riga`: front = RigaDescrizione; back = small row, sentence, `generata`
  Badge when generated.
- `esempio`: front = the map clip and the terrain sketch side by side, each
  on white; back = the printed row image and the sentence.
- `simbolo-isom`: front = the IOF drawing PNG on white, annotations as
  printed; back = small drawing, number Badge, name, geometry, section,
  full description.
- **The rule it carries:** artwork is never recoloured, cropped, stretched or
  redrawn (1.005 licence rule, 2.006). Images carry width and height so
  nothing shifts while they load. Text is verbatim from `content/`.
