# Checkbox

Checkbox with label and optional description. Fills brand blue when checked.

```jsx
<Checkbox id="terms" label="I accept the terms" defaultChecked />
<Checkbox id="news" label="Email updates" description="Product news, once a month." />
```
Sizes `md` (16px) / `lg` (20px). Use `defaultChecked` / `checked`, standard input props.
