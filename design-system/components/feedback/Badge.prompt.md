# Badge

A compact label for statuses, counts, and categories.

```jsx
<Badge variant="soft" color="green">Active</Badge>
<Badge variant="solid" color="blue" pill>New</Badge>
<Badge variant="soft" color="gray" dot>Draft</Badge>
<Badge variant="outline" color="red">Overdue</Badge>
```

- **variant**: `soft` (default), `solid`, `outline`, `white`
- **color**: gray, dark, blue, green, red, yellow, indigo, purple
- `pill` for fully rounded; `dot` for a leading status dot.
