# 005 — Pagina fonti

**Feature ID:** F-005
**Status:** Confirmed — 2026-09-05
**Date:** 2026-09-05
**Owner:** sito ([3.001](../03-modules/001-module-map.md))
**Delivers:** [1.004](../01-vision/004-scope-boundaries.md) attribution page and contact; [3.008](../03-modules/008-security-compliance-and-recovery.md) licence obligations; [1.005](../01-vision/005-constraints.md) licence rules
**Route:** R-005
**Enforced by:** the page is generated from `content/fonti.json` at build; a test asserts every source in the register appears on the page with its licence text; the link check allows this page's external `<a>` targets and nothing else

## Behaviour

A single static page, Italian, listing every source the site reproduces:
title, authors and publisher, edition and date, what orient takes from it,
the licence with a link, and the attribution sentence the licence asks
for. For Purple Pen the BSD notice is reproduced in full; for the IOF
control descriptions the page states that the site is a private family
study aid reproducing extracts of a document Swiss Orienteering
distributes freely, and that the rows marked *generata* are the site's
own compositions. Preline UI and the two typefaces are credited with
their licences. A last line offers a `mailto:` link to the curator for
corrections. The home links here under the deck list; the page links back.

## Components

- Page: `fonti/index.html`, generated by a build step from
  `content/fonti.json` through one template `src/sito/fonti.ts`.
- Content: `content/fonti.json` (register, [3.008](../03-modules/008-security-compliance-and-recovery.md)); licence texts under `content/licenze/`.
- Preline patterns: Card, List group.

## Interfaces

```text
Fonte { id, titolo, autori, editore, edizione, data, licenza: { nome, url, testo? },
        cosaUsiamo: string, attribuzione: string, url? }
```

## States

`default` only.

## Acceptance criteria

- AC-1 Every `Fonte` in the register renders as a section with all its
  fields; adding a source to the JSON adds it to the page with no code
  change.
- AC-2 The Purple Pen licence text appears verbatim; the CC BY-ND link
  resolves to the licence.
- AC-3 The page's only external requests are none; its external links are
  anchors only.
- AC-4 The `mailto:` link opens with a subject naming orient.
